# Адаптер: Claude Code

**Статус: инструмент не установлен.** На машине есть только папка правил, написанных
под его семантику. Адаптер существует, чтобы обвязка развернулась сразу при установке CLI.

## Что важно знать при переносе правил

Правила, написанные для этого инструмента, используют два механизма, которых
**нет** в DeepSeek Harness:

1. **`@`-импорты** — ссылки вида `@rules/base.md` внутри файла инструкций.
   В DSH это просто текст: файл не подключается.
2. **Поиск инструкций выше корня репозитория** — обход вверх по дереву каталогов.
   DSH останавливается на ближайшем `.git` и выше не идёт.

Следствие: десятки килобайт правил, считавшихся активными, в DSH не загружались.
При переносе в ядро они переписаны как обычные политики с фронтматтером —
и теперь работают в любом инструменте, а не только в исходном.

## Раскладка

- Инструкции: `~/.claude/CLAUDE.md`, проектные `CLAUDE.md` и `CLAUDE.local.md`
