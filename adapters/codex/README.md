# Адаптер: Codex

**Статус: CLI не установлен**, на машине остался только каталог конфигурации.

## Раскладка

- Инструкции: `~/.codex/AGENTS.md`; проектные `AGENTS.md` — та же конвенция,
  что у DeepSeek Harness, поэтому ядро переносится без изменений.
- Конфигурация: `~/.codex/config.toml`
- Хранилище доступа: `~/.codex/auth.json` — **в репозиторий не попадает**,
  содержит refresh-токены.

Каталог скиллов у инструмента не подтверждён; в манифесте он объявлен пустым,
чтобы установщик не создавал пустышку. При установке CLI — проверить и заполнить.
