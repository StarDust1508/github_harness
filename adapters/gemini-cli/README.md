# Адаптер: Gemini CLI

## Раскладка

- Инструкции: `~/.gemini/GEMINI.md` — единственная точка подключения правил.
- Каталога скиллов у инструмента нет: в манифесте он объявлен пустым намеренно.
  Если он появится в новой версии — добавить путь и проверить формат.

## Что не переносится

`~/.gemini/oauth_creds.json` и `~/.gemini/google_accounts.json` содержат доступы.
Отдельно: `~/.gemini/history/` может содержать клоны репозиториев с кодом проектов —
это не обвязка, а данные, и в репозиторий обвязки они не идут.
