# Адаптер: Hermes

Слой перевода. Проверено по коду установки (`~/.hermes/hermes-agent-v020`).

## Раскладка скиллов

- Формат: **вложенный**, но обход **рекурсивный** — `rglob("SKILL.md")`.
  Работает и `<категория>/<имя>/SKILL.md`, и плоский `<имя>/SKILL.md`.
- Корень: `~/.hermes/skills` (определяется как `HERMES_HOME / "skills"`).
- Категория берётся из фронтматтера (`category`), если инструмент ждёт вложенность.

**Практический вывод:** установщик кладёт ссылки в `<категория>/<имя>` — это
соответствует родной раскладке инструмента, но не является обязательным.

## Инструкции и состояние

| Что | Путь | Особенность |
|---|---|---|
| Персона | `~/.hermes/SOUL.md` | аналог глобального свода правил |
| Память | `~/.hermes/memories/MEMORY.md`, `USER.md` | личные данные — **в репозиторий не переносятся** |
| Конфигурация | `~/.hermes/config.yaml` | **содержит секреты в открытом виде** (16 непустых) |
| Переменные | `~/.hermes/.env` + бэкапы | 25 активных ключей; бэкапы — тоже секреты |
| Состояние | `~/.hermes/state.db` | большая БД; в репозиторий не идёт |

## Собственные механизмы инструмента

- `tools/skills_hub.py` — свой хаб скиллов (установка из репозиториев).
- `tools/skills_ast_audit.py` — аудит скиллов на уровне AST. Полезно как **внешний
  судья** при приёмке скилла: не самоотчёт, а машинная проверка.
- `agent-hooks/` — хуки на события агента.

## Особенности, о которые легко споткнуться

1. **Секреты лежат в конфиге, а не в окружении.** Правильный шаблон уже есть в том же
   файле: `key_env: NAME`. Переводить по одному, не «переписать всё».
2. **Хранилище состояния хрупкое** — на машине найдены три повреждённые копии БД
   общим объёмом больше гигабайта. Копии состояния — не «бэкап», а мусор;
   в репозиторий не идут и место занимают зря.
3. **Пустые категории-заглушки.** Каталоги без `SKILL.md` выглядят как структура,
   но не содержат ничего. При переносе игнорируются.
4. **Архив скиллов** (`.archive`) не читается инструментом — это склад, а не набор.

## Что этот адаптер не делает

Не переносит память, состояние и секреты. Не пытается «починить» конфиг целиком —
только подключает ядро ссылками.
