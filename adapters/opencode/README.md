# Адаптер: OpenCode

## Раскладка

- Конфигурация: `~/.config/opencode/opencode.json`
- Файл инструкций: `~/.config/opencode/AGENTS.md`
- Каталог скиллов не подтверждён — в манифесте объявлен пустым.

## Известная проблема конфигурации

В `opencode.json` ключ провайдера записан **открытым текстом**, а не через переменную
окружения. Это находка аудита уровня «публиковать нельзя» и повод для ротации ключа.

Правильный шаблон: значение берётся из переменной окружения, а в конфиге остаётся
только её имя. Такой же шаблон уже используется в конфигурации Hermes (`key_env:`).
