# Доказательства

Здесь лежат артефакты, на которые ссылаются реестры. Проверка убеждается,
что файл существует; содержание оценивает человек.

Правила именования — по идентификатору объекта:

- техдокументация системы: `sys-<id>-technical-doc.md`
- остальные артефакты системы: `sys-<id>-<артефакт>.md`
- доказательство меры: `ctl-<id>.md`

Формат один: что это, кто владелец, когда проверено, что именно подтверждает,
и ссылка на первоисточник. Доказательство без даты и владельца — это черновик.
