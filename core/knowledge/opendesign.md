# OpenDesign — конспект

**Сайт:** https://open-design.ai/ · **Код:** https://github.com/nexu-io/open-design · **Лицензия:** Apache-2.0
**Текущая версия (на 2026-09-19):** 0.22.2 (`open-design-0.22.2-mac-arm64.dmg`, ~401 МБ)

## Что это

Открытая альтернатива Claude Design: локальное (local-first) нативное приложение для macOS/Windows, вокруг которого строится agent-native цикл дизайна — *понять бриф → зафиксировать направление → стримить артефакт → критика → выдача*.

Ключевая идея: вместо закрытого продукта — **файловая система функциональных скиллов, шаблонов, дизайн-систем и плагинов**, которые уже установленные на машине кодинг-агенты могут читать, писать и ремиксовать. «Твой CLI становится дизайн-движком, твой ноутбук — студией, а `DESIGN.md` команды — брендовым контрактом.»

## Что генерирует

- веб-прототипы, desktop- и mobile-приложения;
- живые дашборды/артефакты;
- деки (презентации) со спикерскими заметками;
- изображения, видео, motion-графику (HyperFrames);
- документы (многостраничные).

Экспорт: HTML / PDF / PPTX / MP4. Предпросмотр — в песочнице iframe.

## Интеграция с агентами

Два способа:

1. **Потребление OpenDesign агентом** — скиллы, CLI и MCP. Значит, агент (в т.ч. я) может вызывать OpenDesign как инструмент.
2. **Нативные рантаймы** — OpenDesign сам запускает агента. Поддерживаются Claude Code, Codex, OpenCode, Cursor, Qwen, Copilot, Amp, Hermes, Kimi, Antigravity и др.

**DeepSeek Harness — first-class нативный рантайм**: официальный `dsh` CLI, со структурным стримингом, обнаружением моделей, отменой и resume сессии. Настройка: `od agent setup deepseek-harness`.
MCP-установка для других агентов: `od mcp install claude | claude-desktop | codex | reasonix`.

## Установка на этой машине

```sh
brew install --cask open-design      # Homebrew cask, 0.22.2, auto_updates, macOS >= 12
```

Cask ставит `Open Design.app` (аналитика: 1 970 установок за 365 дней — проект живой).

MCP-мост для coding-агентов (в т.ч. для нас) — npm-пакет `open-design-mcp` (v0.16.1): stdio-сервер, соединяющий агента с демоном OpenDesign (BYOK-поток, полная передача systemPrompt). Ставится через `npx -y open-design-mcp`.

## Замечания для работы

- Модели внутри OpenDesign: облачный сервис OpenDesign Cloud (GPT/Claude/DeepSeek для агентов, GPT Image/Seedream/Nano Banana для изображений) **или** BYOK через любой OpenAI-совместимый endpoint.
- Демон сканирует `PATH` для поиска локальных CLI-рантаймов; если приложение запущено из GUI с минимальным `PATH`, рантайм может не находиться — лечится правкой `PATH` процесса или кнопкой *Rescan*.
- Docker-вариант: `deploy/docker-compose.yml`, приложение на `http://127.0.0.1:7456`, токен `OD_API_TOKEN`.

## Почему выбран (решение)

Прямая причина: это единственный из предложенных сервисов, который (а) генерирует **рабочий код и настоящие дизайн-системы**, а не картинки, (б) **официально поддерживает именно `dsh`** как нативный рантайм, (в) работает локально и расширяется файлами, (г) имеет готовый MCP-мост. Альтернативы (Figma, генераторы макетов) не дают агентского контракта `DESIGN.md` и не управляются из харнесса.
