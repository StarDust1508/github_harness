# ux-ui-agent-skills — конспект

**Репозиторий:** https://github.com/plugin87/ux-ui-agent-skills · **npm:** `ux-ui-agent-skills` v2.8.0 · **Лицензия:** MIT

## Что это

Комплект инструкций, дизайн-токенов и runnable-скиллов, превращающий агента в «senior design architect»: дизайн-системы, доступность, продакшн-компоненты. Без сборки, зависимостей и рантайма — **чистый слой знаний**.

Заявленный состав:

- **19 runnable-скиллов**, **44 объективных гейта** качества;
- **DTCG-токены** (design tokens), сборка темы в CSS (`build:tokens`);
- **138 brand-grade дизайн-систем**;
- **16 framework-адаптеров** (React 19, Next.js 15, Tailwind v4, SwiftUI 6 и др.);
- **WCAG 2.2 AA → AAA**, ARIA, i18n/RTL;
- проверки скриптами: контраст (`validate_contrast.py`), хардкод цветов (`lint_hardcodes.py`), ссылки на тему (`validate_theme_refs.py`), размер целей, reduced-motion, фокус-трап, переполнение, клавиатура, скриншот-диффы документации.

Важная деталь: примеры в репозитории — не макеты, а **отрендеренные файлы** из `examples/`, и «то, что видно, прошло гейты». Одна тема → светлый и тёмный режимы без пер-страничных палитр.

## Почему берём

Это единственный из предложенных ресурсов, который добавляет к дизайну **объективные, машинно-проверяемые критерии** (44 гейта), а не только вкус. Это прямо усиливает мой раздел «Проверять»: UI можно не «оценивать на глаз», а прогонять через скрипты-валидаторы.

## Как использовать вместе с OpenDesign

- **OpenDesign** — генерация артефакта и дизайн-система (`DESIGN.md`), движок и предпросмотр.
- **ux-ui-agent-skills** — правила токенов, доступности и **гейты приёмки** для сгенерированного.

Порядок: сгенерировали в OpenDesign → применили токены/DTCG и правила → прогнали гейты (контраст, хардкоды, тема, состояния) → сдали.

## Установка

```sh
npm i -D ux-ui-agent-skills          # или npx без установки
npx ux-ui-agent-skills list          # список скиллов
```

Скиллы раскладываются в агентский каталог; для DSH целевой путь — `~/.dsh/skills`.
