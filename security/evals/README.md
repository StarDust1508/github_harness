# Результаты прогонов

Файлы `<цель>-<дата>.yaml` — машинная запись прогона. Они **коммитятся**:
это доказательство, а не временный файл. Именно на них ссылается мера защиты
в реестре assurance.

Разобрав неоднозначные вердикты (`unclear`), впишите результат в файл.
После правки он отражает проверенное состояние, а не первый машинный проход.

Прогон по цели `self-test` — служебный: он проверяет сам прогонщик,
а не защиту. Его файлы можно не хранить.
